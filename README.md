# AituFindly
FINDLY — локальный сайт для Windows / версия 7: статистика

ЗАПУСК
1. Установи Python с python.org, отметив Add Python to PATH.
2. Распакуй весь архив в отдельную папку.
3. Запусти start.bat. При первом запуске нужен интернет для установки зависимостей.
4. Если пароль администратора ещё не задан, введи его дважды (от 8 символов).
   Символы пароля при вводе не отображаются.
5. Открой http://127.0.0.1:5000.

СТАТИСТИКА
Войди через «Администрация». В верхнем меню появится ссылка «Статистика».
Прямой адрес: http://127.0.0.1:5000/statistics (требуется вход администратора).
Показатели за всё время: все объявления, активные, возвращённые и доля возврата.
Места: топ-8 по количеству объявлений, число активных и доля от ВСЕХ объявлений.
Категории: все категории, количество объявлений, число и процент возвращённых.
Данные читаются из SQLite при каждом открытии/обновлении страницы.
Пустая база и категории без объявлений отображаются без ошибок.

ПЕРЕНОС ДАННЫХ ИЗ ПРЕДЫДУЩЕЙ ВЕРСИИ
Останови сайт и сделай резервную копию старой папки.
Распакуй новую версию отдельно. ДО запуска скопируй из старой папки:
- lost_and_found.db — актуальные объявления;
- static/uploads — загруженные фотографии;
- instance — пароль администратора и ключ сессий, если уже настроены.
После этого запусти новый start.bat. Не заменяй свою актуальную БД базой из архива.
Архив содержит предоставленную демобазу: 112 объявлений.

ОБЪЯВЛЕНИЯ, ФОТО И КАРТА
Новые объявления получают статус «Активно». Только администратор может отметить
вещь возвращённой или снова активировать её на странице объявления.
Фото JPG/PNG/WebP до 8 МБ находятся в static/uploads; в БД хранится путь к файлу.
При добавлении можно выбрать этаж и точку потери на карте AITU.
Раздел «Карта потерь» показывает активные вещи с координатами; остальные есть в списке.
Карта: Yuujiso / meeezzanine, https://yuujiso.github.io/aitumap/ .
Звук успешного добавления и компактные карточки сохранены.

АДМИНИСТРИРОВАНИЕ
Для смены пароля останови сервер, запусти python setup_admin.py, затем start.bat.
Данные хранятся локально. Сохраняй БД и фотографии вместе.
Это учебный локальный прототип: новые объявления создаются от технической учётной
записи Findly Demo; студенческие аккаунты и личные сообщения не реализованы.
Не публикуй проект в интернете без доработки авторизации и защиты.
Для остановки сервера нажми Ctrl+C в его окне.
